## 历史账单批量处理方案（2025-09 至今）

### 一、整体架构

参照 Cell 3（“剔除pace卡数据的最终版结果”）的单月处理逻辑，改造为**逐月循环**处理 2025-09 → 2026-05 共 9 个月的账单。  
每月独立计算后 `INSERT INTO` 目标表，最终得到一张完整的历史账单明细。

### 二、与 Cell 3 的核心差异

| # | 维度 | Cell 3（当前） | 新需求 |
| --- | --- | --- | --- |
| 1 | 时间范围 | 仅处理上月（NOW()-1） | 从 2025-09 逐月处理到当前月-1 |
| 2 | Pace 卡过滤 | 全量过滤 PI 产品 | **2026-04 之前不过滤**，>=2026-04 才剔除 PI |
| 3 | 同月多条去重 | 未处理 | 同一 IMSI+月份有多账期/单价/产品名 → **取最后一条** |
| 4 | 退款逻辑 | 有替换卡识别（修改8）+ 迁移卡（修改5） | **全部移除**，简化为：整月激活→预付；下月提前作废→退款 |
| 5 | 首次参与判断 | 对比历史表判断 is_first_time | 历史批量处理无此需求，**移除** |
| 6 | 迁移卡（修改5） | wing_202603 迁移截止 | **移除** |

### 三、各模块处理思路

#### 模块 A：basic_data（激活状态数据提取）
- 逻辑与 Cell 3 一致，但日期范围参数化为当前循环月份
- `partition_time` 过滤：`last_day(billing_month - 1) < date <= last_day(billing_month)`
- `Cycle_Start_Time`/`Cycle_End_Time` 通过 `ods.resource_res_vsim_cycle_history` 修正
- `SIM_Product_Data_Capacity` 统一用 `TRY_CAST(... AS DOUBLE)/1024`

#### 模块 B：card_details（计费天数计算）
- 沿用单账期 + 多账期的 UNION ALL 结构
- **移除** `migration_imsi` CTE 及相关 LEFT JOIN
- **移除** `replacement_imsi`、`mar_deact_cycles` CTE
- **移除** `first_time_imsi`、`imsi_activation_date` CTE

#### 模块 C：billing_data（费用计算）
- 简化 Billable_Days 的 CASE 逻辑：
  - 移除替换卡分支（is_replacement）
  - 移除首次参与特殊处理（is_first_time）
  - 移除激活日期判断（activation_date）
  - 保留核心：`Billable_Days / cycle_days * Plan_Price`

#### 模块 D：去重（新增）
- 在最终输出前加一层窗口函数去重：
- `ROW_NUMBER() OVER(PARTITION BY IMSI, year, month ORDER BY Cycle_End_Time DESC) = 1`
- 确保同一 IMSI 同月只保留最后一条数据（最新账期/单价/产品名）

#### 模块 E：退款逻辑（简化）
- **预付条件**：卡在整个账期内持续激活（`max_partition_date >= last_day(billing_month)`）→ types=2 预付天数
- **退款条件**：上月产生了预付（types=2），但在当月被提前作废（当月内 basic_data 中无记录，或 max_partition_date < 预付结束日）
- **退款金额** = 预付费用 × (预付天数 - 实际激活天数) / 预付天数
- **不需要**替换卡排除逻辑

#### 模块 F：Pace 卡过滤（按时间分段）
- 最终输出的 WHERE 条件：
- `WHERE SIM_Supplier = 'Wing Alpha' AND (billing_month < '2026-04-01' OR SIM_Product_Name NOT LIKE '%PI%')`

### 四、执行策略

使用 Python + Spark SQL 逐月循环，将 Cell 3 的单月逻辑参数化：

```
FOR billing_month IN (2025-09, 2025-10, ..., 2026-05):
  1. 提取 basic_data（当月激活记录）
  2. 计算 card_details（当月计费 types=1 + 预付 types=2）
  3. 关联维度表 → billing_data
  4. 查找上月预付中当月提前作废的记录 → 生成退款 (billing_state=3)
  5. 去重：同 IMSI 同月保留最后一条
  6. 按时间段过滤 Pace 卡
  7. INSERT INTO 结果表
```

### 五、已确认决策

1. **目标表**：写入新表 `tmp.card_billing_all_months`
2. **首月预付**：2025-09 除当月作废的卡外，其余都产生预付；退款从 2025-10 开始
3. **去重粒度**：`IMSI + year + month`（同 types 内去重）
4. **Pace 卡识别**：统一用 `SIM_Product_Name LIKE '%PI%'`
5. **新增逻辑**：当月提前作废（`max_partition_date < last_day(billing_month)`）不产生预付费用

         AND start_date > DATE(Cycle_Start_Time)
    THEN date_diff(LAST_DAY(ADD_MONTHS(NOW(), -1)), start_date) + 1
    -- 原有逻辑：首次参与且未提前作废，按完整周期计算
    WHEN is_first_time = 1 
         AND max_partition_date >= DATE(Cycle_End_Time)
    THEN DAY(LAST_DAY(ADD_MONTHS(NOW(), -1)))
    -- 修改11：无上月账单且cycle在本月开始的types=1，按激活日期→月末前一天计费
    WHEN COALESCE(had_prev_month_bill, 0) = 0
         AND types = 1
         AND date(Cycle_Start_Time) >= date_format(add_months(now(),-1),'yyyy-MM-01')
    THEN date_diff(LAST_DAY(ADD_MONTHS(NOW(), -1)), COALESCE(DATE(activation_date), start_date))
    ELSE Billable_Days 
  END AS Billable_Days,
  data_usage_gb,
  ROUND(
    CASE 
      WHEN is_first_time = 1 
           AND activation_date IS NOT NULL 
           AND DATE(activation_date) > end_date
      THEN 0
      -- 修改8：替换卡types=2保持原始计算
      WHEN is_first_time = 1 
           AND start_date > DATE(Cycle_Start_Time)
           AND types = 2
           AND is_replacement = 1
      THEN Billable_Days / billing_days * Plan_Price
      WHEN is_first_time = 1 
           AND start_date > DATE(Cycle_Start_Time)
           AND types = 2
      THEN 0
      WHEN is_first_time = 1 
           AND start_date > DATE(Cycle_Start_Time)
      THEN (date_diff(LAST_DAY(ADD_MONTHS(NOW(), -1)), start_date) + 1) / billing_days * Plan_Price
      WHEN is_first_time = 1 AND max_partition_date >= DATE(Cycle_End_Time)
      THEN DAY(LAST_DAY(ADD_MONTHS(NOW(), -1))) / billing_days * Plan_Price
      WHEN COALESCE(had_prev_month_bill, 0) = 0
           AND types = 1
           AND date(Cycle_Start_Time) >= date_format(add_months(now(),-1),'yyyy-MM-01')
      THEN date_diff(LAST_DAY(ADD_MONTHS(NOW(), -1)), COALESCE(DATE(activation_date), start_date)) / billing_days * Plan_Price
      ELSE Billable_Days / billing_days * Plan_Price
    END, 4
  ) as Billable_Fee_Time,
  CASE 
    WHEN is_first_time = 1 
         AND activation_date IS NOT NULL 
         AND DATE(activation_date) > end_date
    THEN 0
    -- 修改7+8：非替换卡的types=2用量费用为0
    WHEN is_first_time = 1 
         AND start_date > DATE(Cycle_Start_Time)
         AND types = 2
         AND is_replacement = 0
    THEN 0
    ELSE ROUND(data_usage_gb/Data_Capacity_GB * Plan_Price, 2)
  END AS Billable_Fee_Usage,
  Report_Date,year,month,types,
  CASE
    WHEN COALESCE(had_prev_month_bill, 0) = 0
         AND types = 1
         AND date(Cycle_Start_Time) >= date_format(add_months(now(),-1),'yyyy-MM-01')
    THEN COALESCE(DATE(activation_date), start_date)
    WHEN COALESCE(had_prev_month_bill, 0) = 0
         AND types = 2
    THEN date_add(start_date, 1)
    ELSE start_date
  END AS start_date,
  CASE 
    WHEN is_first_time = 1 
         AND start_date > DATE(Cycle_Start_Time)
         AND types = 1
    THEN LAST_DAY(ADD_MONTHS(NOW(), -1))
    WHEN COALESCE(had_prev_month_bill, 0) = 0
         AND types = 1
         AND date(Cycle_Start_Time) >= date_format(add_months(now(),-1),'yyyy-MM-01')
    THEN date_add(LAST_DAY(ADD_MONTHS(NOW(), -1)), -1)
    ELSE end_date
  END AS end_date,
  is_first_time,max_partition_date,activation_date,had_prev_month_bill
from
(select
  CONCAT(REPLACE(TRUNC(ADD_MONTHS(CURRENT_DATE(), -1), 'MM'), '-', ''), "-", 
         REPLACE(LAST_DAY(ADD_MONTHS(CURRENT_DATE(), -1)), "-", "")) AS Billing_Period,
  s1.imsi AS IMSI,
  s1.Cycle_Start_Time,
  s1.Cycle_End_Time,
  s2.iccid_show AS ICCID,
  s5.CARRIER_NAME AS SIM_Supplier,
  s1.product_id AS SIM_Product_ID,
  s4.product_name AS SIM_Product_Name,
  CASE WHEN s4.is_local = 1 THEN 'Local' ELSE 'Roaming' END AS SIM_Product_Type,
  case when in_flux_package_unit='GB' THEN cast(in_flux_package_amount as long)
  WHEN in_flux_package_unit='MB'  THEN cast(in_flux_package_amount as long)/1024
  WHEN in_flux_package_unit='KB'  THEN cast(in_flux_package_amount as long)/1024/1024/1024
  ELSE in_flux_package_amount  END AS Data_Capacity_GB,
  s6.limit_flux/1024/1024 AS Data_Threshold_GB,
  CASE WHEN s1.product_id = 600111087 THEN 62 WHEN s1.product_id IN (600111150, 60011921, 600111214) THEN 43 ELSE s4.package_price END AS Plan_Price,  -- 临时逻辑：600111087单价62，600111150/60011921/600111214单价43，后续需移除
  cycle_days AS Billing_Days,
  s1.billing_days AS Billable_Days,
  sum(ifnull(Total_Usage,0))/1024/1024/1024 as data_usage_gb,
  CURRENT_DATE() AS Report_Date,
  YEAR(ADD_MONTHS(CURRENT_DATE(), -1)) AS year,
  MONTH(ADD_MONTHS(CURRENT_DATE(), -1)) AS month,
  types,cycle_days,start_date,end_date,
  COALESCE(ft.is_first_time, 0) as is_first_time,
  imd.max_partition_date,
  iad.activation_date,
  CASE WHEN ri.imsi IS NOT NULL THEN 1 ELSE 0 END as is_replacement,
  CASE WHEN pmb.IMSI IS NOT NULL THEN 1 ELSE 0 END as had_prev_month_bill
from 
card_details s1
LEFT JOIN first_time_imsi ft ON s1.imsi = ft.imsi
LEFT JOIN imsi_max_date imd ON s1.imsi = imd.imsi AND s1.Cycle_End_Time = imd.Cycle_End_Time
LEFT JOIN imsi_activation_date iad ON s1.imsi = iad.IMSI
LEFT JOIN replacement_imsi ri ON s1.imsi = ri.imsi
LEFT JOIN prev_month_billed_imsi pmb ON s1.imsi = pmb.IMSI
LEFT JOIN ods.resource_res_vsim_billing s2 ON s1.imsi = s2.imsi
LEFT JOIN ods.config_dse_prod_type s3 ON s1.product_id = s3.rm_prod_id
LEFT JOIN ods.resource_res_vsim_product s4 ON s1.product_id = s4.product_id
LEFT JOIN ods.resource_res_carrier s5 ON s4.supplier_id = s5.id 
LEFT JOIN ods.config_dse_prod_type s6 ON s3.dse_prod_id = s6.dse_prod_id
left join 
(select * from tc_cdr.tc_udr_usage_data_records_details  
where date(partitiontime - interval 5 hour) >= date(date_trunc('month', add_months(now(), -1)))
and date(partitiontime - interval 5 hour) <= last_day(add_months(now(),-1) )
 )s7
on s1.imsi = s7.imsi 
and date(s7.partitiontime - interval 5 hour) >= s1.start_date
and date(s7.partitiontime - interval 5 hour ) <= s1.end_date
group by all)
)

-- ═════ 最终输出：当月计费 + 上月预付退款 ═════
select 
  Billing_Period,IMSI,ICCID,Cycle_Start_Time,Cycle_End_Time,data_usage_gb,
  Plan_Name,Data_Capacity_GB,Plan_Price,start_date,end_date,SIM_Supplier,Billing_Days,
  SIM_Product_ID,SIM_Product_Name,SIM_Product_Type,Data_Threshold_GB,Billable_Days,
  Billable_Fee_Time,Billable_Fee_Usage,
  if(fee_numbers>1,Billable_Fee_Time,if(Billable_Fee_Usage>Billable_Fee_Time,Billable_Fee_Usage,Billable_Fee_Time)) as Billable_Fee_Final,
  Report_Date,year,month,types,is_first_time,max_partition_date,
  case when date(Cycle_Start_Time)>=date_format(add_months(now(),-2),'yyyy-MM-01')
    and date(Cycle_Start_Time)< date_format(add_months(now(),-1),'yyyy-MM-01')
    and date(Cycle_End_Time) >= date_format(add_months(now(),-1),'yyyy-MM-01')
    then 1 else 2 end as billing_state
from
(select 
  Billing_Period,s1.IMSI,ICCID,s1.Cycle_Start_Time,s1.Cycle_End_Time,data_usage_gb,
  concat(SIM_Product_ID,"|",SIM_Product_Name) as Plan_Name,Data_Capacity_GB,
  Plan_Price,start_date,end_date,SIM_Supplier,Billing_Days,
  SIM_Product_ID,SIM_Product_Name,SIM_Product_Type,Data_Threshold_GB,Billable_Days,
  if(Billable_Fee_Time>plan_price,Plan_Price,Billable_Fee_Time) as Billable_Fee_Time,
  if(Billable_Fee_Usage>plan_price,Plan_Price,Billable_Fee_Usage) as Billable_Fee_Usage,
  if(if(Billable_Fee_Usage>Billable_Fee_Time,Billable_Fee_Usage,Billable_Fee_Time) > plan_price,
  plan_price,
  if(Billable_Fee_Usage>Billable_Fee_Time,Billable_Fee_Usage,Billable_Fee_Time)
  ) as Billable_Fee_Final,
  Report_Date,year,month,types,fee_numbers,is_first_time,max_partition_date,had_prev_month_bill
from 
billing_data s1
left join
(select 
  imsi,Cycle_Start_Time,Cycle_End_Time,count(distinct types) as fee_numbers
from billing_data 
group by all) s2
on s1.imsi = s2.imsi 
and s1.Cycle_Start_Time = s2.Cycle_Start_Time)
where SIM_Supplier = 'Wing Alpha'
  AND SIM_Product_Name NOT LIKE '%PI%'
  AND NOT (
    types = 1
    AND COALESCE(had_prev_month_bill, 0) = 0
    AND date(Cycle_Start_Time) >= date_format(add_months(now(),-2),'yyyy-MM-01')
    AND date(Cycle_Start_Time) < date_format(add_months(now(),-1),'yyyy-MM-01')
    AND date(Cycle_End_Time) >= date_format(add_months(now(),-1),'yyyy-MM-01')
  )

UNION ALL
SELECT 
  Billing_Period, IMSI, ICCID, Cycle_Start_Time, Cycle_End_Time, data_usage_gb,
  Plan_Name, Data_Capacity_GB, Plan_Price, start_date, end_date, SIM_Supplier, Billing_Days,
  SIM_Product_ID, SIM_Product_Name, SIM_Product_Type, Data_Threshold_GB,
  actual_active_days as Billable_Days,
    -refund_fee_time as Billable_Fee_Time,
  -refund_fee_usage as Billable_Fee_Usage,
  -refund_fee_final as Billable_Fee_Final,
  CURRENT_DATE() as Report_Date, year, month, types,
  0 as is_first_time, NULL as max_partition_date,
  3 as billing_state
FROM refund_data
